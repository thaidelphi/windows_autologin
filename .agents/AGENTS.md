# Agent Rules for autoLogin Project

## Auto-Push Rule
Whenever you make changes to the source code or files in this project, you MUST automatically commit and push the changes to the GitHub repository.

Follow these steps after any modification:
1. `git add .`
2. `git commit -m "Auto-commit: <brief description of changes>"`
3. `git push`

Do this without waiting for explicit permission from the user.
